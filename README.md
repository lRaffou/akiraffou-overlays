# Akiraffou — cadre webcam OBS

Page transparente autonome, avec contour animé et glitch discret.

URL : https://lraffou.github.io/akiraffou-webcam/

Dans OBS : source Navigateur, largeur 500, hauteur 280. Placer au-dessus de la caméra et désactiver l’ancien cadre. Le centre reste transparent. Aucun réseau, rang ou widget musique n’est inclus.

## Écran de début
URL : https://lraffou.github.io/akiraffou-webcam/start.html
Source Navigateur OBS : 1920 × 1080. Fond plein écran noir bleuté, titres corail, animation d’attente et glitch discret. L’overlay réseaux horizontal existant est intégré en bas à gauche. Ne pas ajouter une deuxième copie des réseaux sur cette scène. Aucun compte à rebours automatique.
